📊 Sales Analysis Dashboard | Power BI

 📌 Project Overview
This project focuses on analyzing sales performance using Microsoft Power BI. The interactive dashboard provides insights into sales trends, revenue, profit, product performance, and customer behavior to support data-driven business decisions.

 🎯 Project Objectives
- Analyze overall sales and profit performance.
- Identify top-performing products and categories.
- Track sales trends over time.
- Evaluate regional sales performance.
- Generate actionable business insights using data visualization.

 🛠️ Tools & Technologies
- Power BI – Interactive dashboard development and visualization
- Power Query – Data cleaning and transformation
- DAX – Measures and calculated metrics
- Microsoft Excel – Data preparation and analysis

 📈 Key Dashboard Features
- Sales and revenue analysis
- Profit and sales performance tracking
- Product and category analysis
- Regional sales comparison
- Time-based sales trends
- Interactive filters and slicers

 💡 Business Insights
The dashboard helps identify sales trends, high-performing products, profitable categories, and opportunities to improve business performance.

 🚀 How to Use
1. Clone or download this repository.
2. Open the `.pbix` file using Microsoft Power BI Desktop.
3. Refresh the data source if required.
4. Explore the dashboard using interactive filters and slicers.
